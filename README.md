# MYTH Academic Excellence — Cyber Security Suite
### By Kartik Kumar

A modern, high-performance, SaaS-style web platform for **Cyber Security (BCC301 / BCC401)** exam preparation, curated from previous year university question papers and aligned strictly with the official 5-unit syllabus.

## Features
- **Official Syllabus:** Complete 40 lecture hours breakdown (Units 1 to 5), Course Objectives, and Course Outcomes (CO1 to CO4).
- **66 Categorized PYQ Questions:** Extracted from 3 university examination papers with marks (2 & 7 marks) and exact syllabus sequence.
- **Unit 1 Solved Question Bank:** Easy English exam-oriented solutions paired with real-world Hinglish explanation callouts.
- **Pure Black Boxy SaaS Aesthetic:** Minimalist zero-border-radius design inspired by Linear & Vercel.
- **Dual Mode:** Instant Dark Mode & Light Mode switch with persistent local storage.
- **Offline Printable PDFs:** Downloadable question bank and solved answer sheets.
- **Local State Tracking:** "Mark as Learnt" functionality saved directly on device.
